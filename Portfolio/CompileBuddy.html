CompileBuddy
Github Repository  Introducing CompileBuddy, your new C++ companion! I built this to make compiling C++ projects faster, easier, and a little more friendly. It is a lightweight GUI that wraps g++, letting you run, debug, and manage your builds with a single click.
 The application is written in C++ and uses the popular wxWidgets library, which allows you to write cross-platform applications using OS native widgets and UI elements.
