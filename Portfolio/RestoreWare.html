RestoreWare
LinkedIn Post  RestoreWare is an application for repairing and maintaining Windows 10 and 11 operating systems. It is entirely written by hand in Rust and PowerShell.
 RestorWare provides a quick and accessible GUI for running powershell scripts for device maintainance and repairs. It contains many small scripts called QuickTools, shortcuts to commonly used or hidden menus, and larger utilites that pass values from input fields to PowerShell scripts for increased functionality and customizability.
